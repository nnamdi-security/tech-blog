# Thumbnail generator

Renders the bold, dark post thumbnails used on the blog. Each thumbnail is a small HTML page that a headless browser screenshots at 1600 × 1000, so text, fonts, and layout look identical on every device.

For each thumbnail it writes two files to `assets/images/posts/`:

| File | Used for |
| --- | --- |
| `<name>.webp` (~50 KB) | Post cards, the featured post, and post cover images |
| `<name>.jpg` (~120 KB) | `og:image` and `twitter:image` social previews (not every platform accepts WebP) |

## One-time setup

You need [Node.js](https://nodejs.org/) 18 or newer. From the repository root:

```bash
npm install --no-save playwright
```

```bash
npx playwright install chromium
```

`--no-save` installs Playwright without adding a `package.json` to the site. `node_modules/` is ignored by Git.

Fonts (Anton, Inter, JetBrains Mono) load from Google Fonts while rendering, so you need an internet connection.

## Make a thumbnail for a new post

1. Open `tools/thumbnails/thumbnails.js` and add an entry. The key becomes the file name:

   ```js
   "css-grid-basics": simpleThumbnail({
       accent: "#38bdf8",                     // accent colour for badge, highlight, and checks
       badge: "Video tutorial",               // top-left label
       title: "CSS Grid",                     // big white headline
       highlight: "in 10 minutes",            // second line on an accent band
       points: ["Rows & columns", "Grid areas", "Responsive layouts"], // up to 3
       code: ".layout {\n  display: grid;\n  gap: 2rem;\n}",          // optional code window
       meta: "▶ 10:24",                       // bottom-right: duration or "6 MIN READ"
       video: true                            // adds a play button
   }),
   ```

2. Render just that thumbnail:

   ```bash
   node tools/thumbnails/generate.js css-grid-basics
   ```

3. Reference the files in your post:
   - `posts.js`: `thumbnail: "/assets/images/posts/css-grid-basics.webp"`
   - The post page's cover image: `../../assets/images/posts/css-grid-basics.webp`
   - `og:image`, `twitter:image`, and JSON-LD: `https://techbrosis.netlify.app/assets/images/posts/css-grid-basics.jpg`

## Other commands

Re-render every thumbnail:

```bash
node tools/thumbnails/generate.js
```

Render into a different folder to preview without touching the site:

```bash
node tools/thumbnails/generate.js --out ./thumbnail-preview
```

## Tips

- Keep headlines short: two to five words read best on a small card.
- Pick an accent colour that differs from nearby posts so the archive stays varied.
- For a custom layout, copy one of the existing entries. They use the same helpers (`page`, `windowBar`, `playButton`, `checklist`) from `template.js`, plus the CSS classes defined there (`.t` for headline type, `.hl` for the accent band, `.win` for a code window).
- The Variables tutorial thumbnail (`javascript-variables.png`) was made separately and is not generated by this tool.
