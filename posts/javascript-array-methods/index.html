JavaScript Array Methods Explained

Learn how map, filter, find, and reduce help you transform real application data.

Nnamdi Ileh 16 July 2026 Updated 18 July 2026 18:42 video
  • JavaScript
  • Frontend
  • Tutorial

Arrays appear everywhere in JavaScript: product lists, API responses, search results, form data, and application state. The methods in this lesson help you work with those collections without writing repetitive loops.

What you will learn

  • How callback functions work inside array methods.
  • When to use map, filter, find, and reduce.
  • How to avoid accidentally changing the original array.

Prerequisites

You should understand variables, functions, arrays, objects, and basic for loops. You do not need experience with frameworks.

1. Start with a useful data set

We will work with a small list of course objects. Each object contains a title, category, price, and publication status.

const courses = [
    { title: "HTML Foundations", category: "frontend", price: 0, published: true },
    { title: "Practical Laravel", category: "backend", price: 25000, published: true },
    { title: "CSS Layout Systems", category: "frontend", price: 15000, published: false }
];

2. Transform every item with map

Use map when you want one output value for every input item. It returns a new array and leaves the original array unchanged.

const courseTitles = courses.map((course) => course.title);

console.log(courseTitles);
// ["HTML Foundations", "Practical Laravel", "CSS Layout Systems"]

3. Keep matching items with filter

Use filter when zero, one, or many items may match a condition.

const publishedCourses = courses.filter(
    (course) => course.published
);

4. Return one match with find

Use find when you need the first matching item rather than an array of every match.

const laravelCourse = courses.find(
    (course) => course.title === "Practical Laravel"
);

if (laravelCourse) {
    console.log(laravelCourse.price);
}

5. Combine values with reduce

reduce carries an accumulated value from one item to the next. Here, the accumulator begins at zero.

const totalPrice = courses.reduce(
    (total, course) => total + course.price,
    0
);

console.log(totalPrice); // 40000

Common mistakes

  • Using map but forgetting to return a value from the callback.
  • Using find and assuming a result always exists.
  • Using reduce for simple operations that would be clearer with another method.
  • Changing objects inside a method without realising the original object is still referenced.

Useful resources

  • MDN: Array.prototype.map()
  • MDN: Array.prototype.filter()
  • MDN: Array.prototype.reduce()

Conclusion

Choose the method that best describes your intention: transform with map, select many with filter, select one with find, and combine values with reduce.
